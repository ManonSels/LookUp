#### Description
-------------------
LookUp is a full-stack web application deployed on an Ubuntu server using PM2 and Nginx. Built with Flask, pure JavaScript, HTML, and CSS. There's an admin dashboard with drag-and-drop content management, category organization, and markdown support for creating "cheatsheets" and reference guides.
